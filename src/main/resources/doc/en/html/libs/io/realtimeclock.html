Real-Time Clock

Library: Input/Output

Behavior

Outputs the current time since the Unix epoch, 1970-01-01 00:00:00 UTC. The value is expressed in either milliseconds or seconds. The component refreshes automatically and does not require a clock input.

Pins

The component has one 64-bit output. Its value is the current epoch time in the unit chosen by the Time Type attribute.

Attributes

When the component is selected or being added, the arrow keys alter its Facing attribute.

Facing
The location of the output pin relative to the component.
Time Type
Selects epoch milliseconds or epoch seconds for the output.
Draw size
Selects the medium or narrow component appearance.

Poke Tool Behavior

None.

Text Tool Behavior

None.
