min/max Floating Point Minimum and Maximum

Library: Floating Point Arithmetic

Behavior

This component compares its two west inputs. The upper east output contains their minimum and the lower east output contains their maximum. For positive and negative zero, the minimum is negative zero and the maximum is positive zero.

If either input is NaN, both results are NaN and ERR is 1. An input containing unknown or error bits is converted to NaN. Infinities otherwise participate in the comparison normally.

Pins

West edge, north end (input, bit width matches Float size)
The first value to compare.
West edge, south end (input, bit width matches Float size)
The second value to compare.
East edge, north end (output, bit width matches Float size)
The minimum of the two inputs.
East edge, south end (output, bit width matches Float size)
The maximum of the two inputs.
South edge (output, bit width 1)
ERR: 1 if either input is NaN; otherwise 0.

Attributes

Float size
The floating-point width of both inputs and both results: 8, 16, 32, or 64 bits.
