Floating Point Arithmetic library

The Floating Point Arithmetic library contains components that operate on floating-point values. The Float size attribute selects an 8-bit minifloat (one sign bit, four exponent bits, and three fraction bits), or an IEEE 754 binary16, binary32, or binary64 representation.

The arithmetic and mathematical-function components documented here provide a one-bit ERR output. It is 1 when the component's primary result is NaN and 0 otherwise. An input containing unknown or error bits is converted to NaN.
