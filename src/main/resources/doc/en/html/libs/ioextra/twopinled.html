2-Pin LED

Library: Input/Output-Extra

Behavior

Models an LED with separate anode and cathode connections. It uses On Color only when the anode is 1 and the cathode is 0. With Bipolar enabled, it uses Reverse Color when the anode is 0 and the cathode is 1. All equal, unknown, or error input combinations display Off Color.

The component can also be placed in a circuit's dynamic appearance.

Pins

Anode (1 bit)
The LED's anode input.
Cathode (1 bit)
The LED's cathode input.

Attributes

Facing
Controls the orientation of the diode symbol and the anode and cathode pins.
On Color
The color displayed for forward polarity.
Off Color
The color displayed when the LED is off.
Bipolar
Enables a distinct color for reverse polarity.
Reverse Color
The color displayed for reverse polarity when Bipolar is enabled.
Label
The text associated with the component.
Label Location
The location of the label relative to the component.
Label Font
The font used to draw the label.
Label Color
The color used to draw the label.
Label Visible
Controls whether the label is displayed.

Poke Tool Behavior

None.

Text Tool Behavior

Allows the label associated with the component to be edited.
