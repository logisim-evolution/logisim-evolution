Матричная клавиатура

Библиотека: Ввод/вывод

Поведение

Моделирует матричную клавиатуру 4×4. Нажатие клавиши соединяет её вход строки с выходом столбца, позволяя схеме сканировать клавиатуру аналогично физической матричной клавиатуре. При отпускании кнопки мыши клавиша отжимается.

Атрибут Режим работы выбирает один из двух вариантов электрического поведения.

Обычная матрица
Пока клавиши не нажаты, выходы (строки) находятся в высокоимпедансном состоянии (Z). Нажатие клавиши передает сигнал с соответствующего входа (столбца) на соответствующий выход (строку).
Pmod KYPD (с внутренней подтяжкой)
По умолчанию на выходах (строках) удерживается логическая 1. Нажатие клавиши передает сигнал с соответствующего входа (столбца) на соответствующий выход (строку). В этом режиме используется фиксированная раскладка модуля Pmod KYPD (символы 0, F, E и D в нижнем ряду).

Контакты

Четыре 1-разрядных входа (столбцы) расположены вдоль нижнего края, а четыре 1-разрядных выхода (строки) — вдоль правого края. Пока клавиша удерживается нажатой, она физически замыкает между собой вход и выход, на пересечении которых находится.

Атрибуты

Режим работы
Выбирает поведение «Обычная матрица» или «Pmod KYPD», как описано выше.
Размер отображения
Выбирает обычный или крупный внешний вид клавиатуры.
Символ клавиши 'A', 'B', 'C', 'D', '*' и '#'
Настраивает отображаемые символы для этих шести клавиш в режиме «Обычная матрица». Режим Pmod KYPD использует фиксированные метки и скрывает эти атрибуты.
Метка
Текст, связанный с компонентом.
Положение метки
Расположение метки относительно компонента.
Шрифт метки
Шрифт, используемый для отрисовки метки.
Цвет метки
Цвет, используемый для отрисовки метки.
Отображать метку
Управляет отображением метки.

Поведение инструмента «Нажатие»

Нажмите и удерживайте клавишу, чтобы замкнуть соответствующий вход (столбец) с выходом (строкой). Клавиша остаётся нажатой до тех пор, пока не будет отпущена кнопка мыши.

Поведение инструмента «Текст»

Позволяет редактировать метку, связанную с компонентом.
