Светодиодная шкала

Библиотека: Ввод/вывод

Поведение

Компонент представляет собой ряд светодиодных сегментов. По умолчанию ряд горизонтальный, а его короткая сторона занимает 3 клетки сетки. Атрибут Направление поворачивает шкалу, в том числе вертикально, а Толщина задаёт, сколько клеток занимает короткая сторона. Если на вход сегмента подаётся логическая 1, он светится цветом, заданным атрибутом Цвет во включенном состоянии. При подаче логического 0 применяется Цвет в выключенном состоянии. Неопределённое (Z/U) или ошибочное (E) состояние на входе отображается стандартным цветом ошибки симулятора.

Контакты

Конфигурация входных контактов зависит от значения атрибута Формат входа.

Раздельные
Компонент предоставляет отдельные 1-разрядные входы для каждого сегмента шкалы.
Одна шина
Компонент имеет единственный многоразрядный вход, ширина которого равна заданному количеству сегментов. При направлении по умолчанию (восток) младший разряд (бит 0) управляет крайним правым сегментом шкалы. При повороте этот конец шкалы перемещается вместе с компонентом.

Атрибуты

Формат входа
Переключает режим подключения между отдельными 1-разрядными линиями и единой многоразрядной шиной.
Направление
Направление шкалы. Восток — прежнее горизонтальное расположение, сегменты идут вправо. Север и юг ставят шкалу вертикально. Стрелки поворачивают выделенную шкалу.
Толщина
Короткая сторона шкалы в клетках сетки, от 1 до 8. Значение по умолчанию — 3: так выглядели шкалы, сохранённые до появления этого атрибута. Значения 2 и 4 совпадают по шагу с компонентами, выстроенными по 2 или 4 клетки, в том числе когда несколько вертикальных шкал стоят рядом.
Сегменты
Задаёт общее количество светодиодных сегментов в шкале. Значение по умолчанию — 8.
Управляющий вход
Определяет расположение входных контактов: на нижней/левой или верхней/правой стороне компонента.
Цвет во включенном состоянии
Задаёт цвет свечения сегмента, на который подан логический 1.
Цвет в выключенном состоянии
Задаёт цвет сегмента, на который подан логический 0.
Продолжительность затухания
Позволяет сегменту плавно затухать, оставаясь включенным в течение заданного количества тактов моделирования после перехода входного сигнала в 0. Значение 0 отключает эффект послесвечения.
Метка
Текстовая подпись, привязанная к компоненту.
Положение метки
Определяет пространственное расположение текста метки относительно корпуса компонента.
Шрифт метки
Шрифт, используемый для отрисовки текста метки.
Цвет метки
Цвет, используемый для отрисовки текста метки.
Отображать метку
Управляет видимостью текстовой метки на чертеже.

Поведение инструмента «Нажатие»

Отсутствует.

Поведение инструмента «Текст»

Позволяет редактировать текстовую метку, привязанную к компоненту.
