Ползунок

Библиотека: Дополнительный ввод/вывод

Поведение

Выдает беззнаковое значение, которое задается путем перетаскивания бегунка. Для разрядности в n бит выходное значение находится в диапазоне от 0 до 2n − 1. Текущее значение отображается в выбранной системе счисления.

Контакты

Компонент имеет один выход. Его разрядность задается атрибутом Биты данных и может составлять от 1 до 8 бит.

Атрибуты

Направление
Определяет пространственную ориентацию компонента на чертеже.
Биты данных
Разрядность выхода (от 1 до 8 бит).
Система счисления
Система счисления, используемая для отображения текущего значения.
Цвет
Цвет заливки корпуса ползунка.
Метка
Текстовая подпись, привязанная к компоненту.
Шрифт метки
Шрифт, используемый для отрисовки текста метки.
Отображать метку
Управляет видимостью текстовой метки на чертеже.
Направление шкалы
Определяет, увеличиваются ли значения слева направо или справа налево. При изменении этого атрибута текущее значение сохраняется за счет автоматического перемещения бегунка в зеркальное положение.

Поведение инструмента «Нажатие»

Позволяет перетаскивать бегунок для задания выходного значения.
