Библиотека Дополнительный ввод/вывод

Библиотека «Дополнительный ввод/вывод» содержит интерактивные элементы управления, индикаторы, аудиовыход, визуализацию сигналов и программируемую логическую матрицу (ПЛМ).

  ПЗУ на основе ПЛМ
  Переключатель
