Переключатель

Библиотека: Дополнительный ввод/вывод

Поведение

Моделирует ручной перекидной переключатель. При добавлении на схему он по умолчанию замкнут на первый контакт. Клик мышью по компоненту переключает соединение между первым и вторым контактами.

Контакты

Назначение контактов (вход или выход) зависит от атрибута Режим переключения.

1 вход → 2 выхода
Сигнал с общего входа передается на выбранный выход. Невыбранный выход находится в неопределенном состоянии.
2 входа → 1 выход
Сигнал с выбранного входа передается на общий выход.

Все три контакта имеют разрядность, заданную атрибутом Биты данных.

Атрибуты

Режим переключения
Выбирает направление передачи сигнала: «1 вход → 2 выхода» или «2 входа → 1 выход».
Направление
Пространственное направление от общего контакта к паре переключаемых контактов.
Биты данных
Разрядность всех трех контактов.
Цвет
Цвет заливки корпуса переключателя; белый цвет (по умолчанию) оставляет корпус прозрачным.
Метка
Текстовая подпись, привязанная к компоненту.
Положение метки
Расположение метки относительно компонента.
Шрифт метки
Шрифт, используемый для отрисовки текста метки.

Поведение инструмента «Нажатие»

Кликните по переключателю, чтобы перевести его на другую ветвь.
