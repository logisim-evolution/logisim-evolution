Цифровой осциллограф

Библиотека: Дополнительный ввод/вывод

Поведение

Записывает состояние тактового сигнала и каждого 1-разрядного входного сигнала при каждом изменении уровня тактового сигнала между 0 и 1. Когда область отображения заполняется, старые выборки сдвигаются влево по мере добавления новых справа. Если входной сигнал изменяется уже после фронта тактового импульса, его последнее записанное значение на осциллограмме обновляется. Благодаря этому осциллограф позволяет наглядно видеть задержки распространения сигнала в моделируемой схеме.

Запись приостанавливается, пока на входе Enable установлен 0. Установка значения 1 на входе Clear очищает историю и сбрасывает нумерацию фронтов тактового сигнала. Неопределенный тактовый сигнал не вызывает запись выборки; неопределенные или ошибочные значения входных сигналов отображаются как разрывы на их осциллограммах.

Контакты

Тактовый вход
Тактовый сигнал для выборки. Выборки добавляются как по переднему (нарастающему), так и по заднему (спадающему) фронтам.
Входы сигналов
Сигналы, графики которых располагаются под линией тактового сигнала (если её отображение включено).
Разрешение
Значение 0 приостанавливает запись; другие значения разрешают запись.
Очистить диаграмму
Значение 1 удаляет все записанные выборки.

Атрибуты

Количество входов
Определяет количество сигнальных входов (от 1 до 32).
Количество состояний
Определяет ширину отображаемой истории: от 4 до 35 тактовых циклов.
Отрисовка линий фронтов
Рисует вертикальные направляющие линии: не рисовать, по переднему фронту, по заднему фронту или по обоим фронтам.
Отображать тактовый сигнал
Управляет видимостью осциллограммы тактового сигнала и номеров фронтов.
Цвет рамки
Задаёт цвет рамки и направляющих линий.
Метка
Текстовая подпись, привязанная к компоненту.
Положение метки
Определяет пространственное расположение текста метки относительно корпуса компонента.
Шрифт метки
Шрифт, используемый для отрисовки текста метки.
