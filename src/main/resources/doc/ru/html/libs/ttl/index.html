Библиотека ТТЛ

Библиотека ТТЛ содержит цифровые функциональные модели интегральных микросхем 74-й серии (в отечественной номенклатуре им соответствуют серии К155, К555, КР1533 и их модификации) в стандартных корпусах DIP. Необходимая микросхема выбирается по её базовому номеру.

По умолчанию выводы питания микросхем скрыты — предполагается, что они неявно и корректно подключены к источнику напряжения. Чтобы отобразить их на графическом символе компонента, активируйте атрибут Отображать выводы Vcc и GND. Кроме того, настройка Показать внутреннюю структуру позволяет визуализировать внутреннюю логическую схему элемента (эта функция доступна для компонентов, поддерживающих данный режим).

Примечание:

Данные компоненты моделируют исключительно функциональную цифровую логику, а не реальные электрические характеристики или точные аппаратные задержки. Для получения достоверных сведений о цоколёвке, таблицах истинности, предельных эксплуатационных параметрах и других аппаратных особенностях конкретного устройства всегда обращайтесь к официальной технической документации производителя.
