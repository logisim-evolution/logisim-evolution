命令行选项

命令行选项可用于设置启动首选项、在无图形界面的环境中运行工程，或执行验证与 FPGA 流程。基本语法如下： 

java -jar jarFileName [选项] [工程文件]

没有被选项作为参数使用的工程文件将由 Logisim-evolution 打开。下文以长选项名为主；如果 选项有对应的短名称，则一并列出。例如： 

java -jar jarFileName --user-template plain --gates ansi --locale zh

常规选项

-h, --help

显示当前命令行选项摘要，然后退出。

-v, --version

显示版本与构建信息，然后退出。

--clear-prefs

在启动时清除已保存的应用首选项。

-g, --gates [ansi|iec]

选择 ANSI 形状或 IEC 矩形逻辑门符号。

-m, --geometry 宽度x高度[+X+Y]

设置主窗口尺寸；如果提供 X、Y，还会设置窗口左上角的位置。例如： --geometry 600x400+100+100。

-o, --locale 语言代码

选择以下受支持的 locale 代码之一：

de 德语
el 希腊语
en 英语
es 西班牙语
fr 法语
pt 葡萄牙语
ru 俄语
it 意大利语
nl 荷兰语
ja 日语
pl 波兰语
zh 简体中文
-u, --user-template [empty|plain|文件]

选择空模板、默认普通模板，或一个可读取的自定义模板文件。

--no-splash

启动时隐藏启动画面。

-s, --substitute 库文件1 库文件2

加载工程时，用库文件2替换对库文件1的引用。参见 替换库。

TTY 仿真选项

-t, --tty 格式[,格式...]

在无图形界面的环境中运行。格式可用逗号组合，支持 table、 speed、tty、halt、stats、binary、 hex、csv 和 tabs。参见 其他验证选项。

-l, --load 文件 [标签]

在 TTY 仿真前加载内存映像。指定标签时，映像用于标签匹配的 RAM 和 ROM；不指定 标签时，它将作为其他内存的默认映像。可以针对不同标签重复使用此选项，且只能与 --tty 一起使用。

--save 文件

TTY 运行结束后，将 RAM 内容保存到内存映像文件。此选项只能与 --tty 一起使用。

--toplevel-circuit 名称

选择要作为顶层电路使用的电路。

验证与转换选项

-w, --test-vector 电路 向量文件 工程文件

使用向量文件测试工程文件中的指定电路，完成后退出。参见 测试向量。

-b, --test-circuit CIRC 文件

打开工程并运行其中的测试台，报告成功或失败，然后退出。

-n, --new-file-format 输入文件 输出文件

将输入文件作为 Logisim 工程打开，再使用当前 Logisim-evolution 文件格式写入 输出文件。

FPGA 选项

-f, --test-fpga CIRC 文件 电路 板卡 [时钟频率] [HDLONLY]

为指定电路和板卡执行 FPGA 实现流程。可选时钟频率以 Hz 为单位； HDLONLY 表示生成 HDL 后停止。两个可选值可按任意顺序提供。

--fpga-cable 名称

按工具报告的完整名称选择 Intel/Altera Quartus 线缆。此选项必须与 --test-fpga 一起使用，并且仅适用于 Intel/Altera 目标。
